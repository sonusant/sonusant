### 👨‍💻 About Me

I am a Senior Software Developer and Tech Lead specializing in **high-scale Shopify Plus ecosystems**, **Python backend engineering**, and **cross-system enterprise data architecture**.

Over the past 5 years, I've designed and supported critical middleware and bidirectional pipelines connecting **Shopify Plus (B2B/B2C)** with core ERP backends like **NetSuite** and **Frappe/ERPNext**. My focus is on fault-tolerant systems: zero-data-loss event streaming, automated retry/backoff workflows, and high-throughput data processing.

- 🔭 **Current Focus:** Enterprise commerce middleware, GraphQL bulk operations, and custom ERP workflow automation.
- ⚡ **Engineering Principles:** Idempotency, fault tolerance, observable background queues, and clean code hygiene.
- 🤝 **Leadership:** Experienced leading engineering teams of 4–6 developers across sprint delivery, technical design, and code quality.
- 💬 **Ask me about:** Shopify Plus B2B architecture, Frappe DocTypes, SuiteQL/RESTlets, asynchronous Python, and Neo4j AST parsing.
